# NewzlerApp — Flutter News App

A modern news app frontend delivering live 
YouTube videos, trending stories, and real-time 
updates. Social login, onboarding flow, trending 
feed, and video integration — cross-platform 
from one Flutter codebase.

## Features
- Live YouTube video integration
- Trending news feed
- Social login (Google, Facebook, Twitter)
- Onboarding flow
- Category filtering
- Bottom navigation
- Fast, clean, distraction-free reading

## Tech Stack
- Flutter & Dart
- REST APIs
- YouTube API integration
- Firebase Authentication

## Getting Started
Clone the repo and run flutter pub get.
